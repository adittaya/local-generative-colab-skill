Installation prompt 
Install and use the skill at:
https://github.com/adittaya/local-generative-colab-skill

Do not ingest every reference at startup. Read SKILL.md and references/workflow-contract.md first. Then load only the reference needed for the current task.

PRE-FLIGHT
1. Verify actual local shell/file access and the installed CLI syntax.
2. Verify authentication without printing secrets. A config file existing does not prove authentication.
3. Verify remote backend availability and quota with a harmless status check. Do not claim GPU access until a submitted job confirms it.
4. If a required capability is unavailable, report the blocker and offer a realistic fallback. Do not pretend to execute.

EXECUTION
1. Create a project workspace, run ID, manifest and logs before heavy work.
2. Select one backend based on verified availability, quota, task fit and cost. Kaggle-first is a preference, not a claim that it is always available. Use Colab only when verified and appropriate.
3. Read only the specialist references needed for the task: model discovery/selection for a concrete model task; visual reconstruction for frame reconstruction; asset extraction for editable assets; 3D generation for 3D; video generation for generated motion; audio/voice for those deliverables; persistence and remote-compute guidance for remote jobs.
4. Pin model IDs/revisions and record license/source, hardware fit, config, seed when available, job ID and outputs.
5. Treat remote disks as temporary. Persist inputs/config first; retrieve outputs and logs immediately after completion; validate files and hashes where practical.
6. Use bounded retries (at most two by default for transient failures). Never retry deterministic errors blindly. Respect quotas; do not launch unbounded parallel jobs.
7. Stop remote sessions when their work is complete. Never leave idle sessions running.

QUALITY AND DELIVERY
- Quality > fidelity to source/brief > editability > speed, while staying truthful about capability and licensing.
- Never claim a job completed because it was submitted. Confirm retrieved artifacts exist, are non-empty, decode, and match expected metadata.
- For video, verify duration, dimensions, frame rate, codecs, audio streams and synchronization; inspect actual frames and listen when review tools are available.
- Keep original assets, avoid secrets in logs/commits, and record all outputs and known limitations.
- Deliver artifacts, logs/manifest, validation results and blockers. State clearly what was not tested.

Start with a short capability report and staged plan, then execute only work the environment can actually perform.
